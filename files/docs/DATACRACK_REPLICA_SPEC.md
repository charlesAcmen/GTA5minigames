# GTA V Data Crack Web 复刻规范

## 视觉

- 使用 1280×720 逻辑舞台，外层窗口与现有小游戏共用 `left:186px; top:52px; width:900px; height:616px`。
- 蓝框为 `rgb(26,68,176)`，内容区为带暗灰透视斜线网格的黑色背景。
- 标题使用 `files/Datacrack/docs/DataCrack-GTAO-Logo1.webp` 的运行时副本；参考截图本身不进入运行时包。
- 红框为 548×430px，中央红线高 24px；八列各含两个 28×96px 白块，上下间隙同为 24px。锁定后两块白条分别与红线的上下边缘严格接壤。
- 当前列使用 4px 黄色描边；已经命中的列恢复白色并将间隙中心精确固定在红线中心。

## 数据与运动

- 固定使用八列，初始共享相位为 `0.25`，每列额外增加 `1/16` 周期，形成等间隔相位序列。
- 所有未锁定列由同一个共享相位驱动，使用正弦往返运动；列间只有固定相位差，不允许各自累计时间或频率漂移。
- 初始完整周期为 2200ms，每锁定一列后周期乘以 `0.93`，最后阶段约为 1323ms；提速只改变后续相位增量，不重置共享相位。
- 垂直振幅为 85px；当前列间隙中心距红线中心不超过 15px 时判定命中。
- 命中后不能冻结在提交帧的近似位置，必须渲染为零偏移，从而与红线严格同心。

## 输入与状态

- Enter、Space 或单击游戏板提交当前列；列按从左到右的固定顺序激活，不能手动横向选择。
- 正确提交播放 `hit.wav` 并锁定当前列；其余未锁定列立即按下一档共享速度继续连续运动。
- 错误提交播放 `wrong.wav`；若已有锁定列，则解锁最近一列并退回该列，第一列失误时保持在第一列。
- 游戏没有倒计时、机会数或终局失败，可持续尝试直至八列全部锁定。
- 最后一列命中后，全部八列保持精确对齐 650ms，再显示 `HACK COMPLETE`；成功音效在最后一次命中时播放。
- 完成画面按任意键或单击返回 External Device；Esc 在任意阶段直接返回。
